# CodeNest Learning v1.2.5

## New learning workflow features

- Added daily one-lesson goal progress and lightweight achievement badges on Home.
- Added lesson bookmarks inside the video player with persistent local storage.
- Added lesson notes with a local editor and 500-character limit.
- Expanded Home global search to include lesson title, category and course title matches.
- Added a responsive tablet/desktop two-column Course detail layout: course summary on the left and lessons on the right.
- Kept Premium offline lesson save state separate from lesson bookmarks.
