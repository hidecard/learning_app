# Nexus Tech Learning App v1.2.3

This release completes the Premium offline lesson feature. Premium members can tap Download inside the video player to save a lesson in the device's offline library state. The action is protected by the Firebase-backed Premium status and non-Premium users are sent to Premium activation. The saved state persists locally and is reflected in the Profile library count and the player button state.

This release deliberately does not rip or copy YouTube video files. The app stores the permitted lesson/offline-library state; actual media caching requires a first-party downloadable media endpoint rather than a YouTube URL.

Premium comparison and benefit screens now explain offline lesson saves, and the download button supports add/remove behavior with clear feedback.
